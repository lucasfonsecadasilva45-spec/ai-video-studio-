# 04 — Sistema de créditos

Regra inicial sugerida:
- Cadastro: 20 créditos.
- Geração: reservar créditos antes de criar a tarefa.
- Sucesso: manter o débito.
- Falha técnica: devolver os créditos.
- Cada modelo/duração pode ter custo diferente.

O débito deve ocorrer no backend dentro de uma operação segura, nunca somente no navegador.
