# 02 — Supabase

No Supabase:
1. Crie um projeto.
2. Ative Auth por e-mail.
3. Crie um bucket privado chamado `videos`.
4. Crie um bucket privado chamado `inputs`.
5. Execute o SQL em `supabase/schema.sql`.
6. Mantenha RLS ativo.
7. Copie URL e publishable key para o `.env`.

O banco guarda metadados; vídeos grandes ficam no Storage.
