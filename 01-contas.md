# 01 — Contas e chaves

Criar:
- Supabase: projeto para Auth, PostgreSQL e Storage.
- Runway Developer: chave para geração de vídeo.
- Provedor de pagamentos: Mercado Pago ou Stripe.
- Hospedagem: Vercel ou outro host compatível com Node/Next.

Nunca coloque a chave secreta da Runway no JavaScript do navegador.
