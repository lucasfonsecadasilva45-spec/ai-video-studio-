# 10 — Deploy

1. Suba o projeto para GitHub.
2. Conecte o frontend/backend a uma hospedagem compatível.
3. Cadastre variáveis de ambiente no host.
4. Configure Supabase.
5. Configure webhook de pagamentos.
6. Configure domínio.
7. Ative HTTPS.
8. Faça testes com conta de teste.
9. Só depois habilite pagamentos reais.
