# 07 — Imagem → vídeo

1. Usuário escolhe uma imagem.
2. Frontend envia para o backend.
3. Backend valida tipo/tamanho.
4. Backend salva em Storage privado.
5. Backend fornece a referência aceita pelo provedor.
6. Cria a tarefa image-to-video.
7. Acompanha a tarefa.
8. Salva o resultado na biblioteca.

Também podemos adicionar video-to-video posteriormente.
